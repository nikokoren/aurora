  Aurora Watch, Half Horizontal view (800x240 on OG landscape). Wide,
  short: verdict and, when there's anything to say about timing, the
  time window and compass hint stacked directly underneath it, all in
  one growing left block, rather than a fixed-width right column that
  sat mostly blank on quiet nights and awkwardly held two short lines
  on busy ones. The reclaimed right side is a compact 3-night forecast
  strip instead, mirroring Quadrant's proven verdict + 3-night layout,
  just side by side here instead of stacked, there's the width for it.
  Only present when there's forecast data at all; the left block grows
  to fill the full width on its own when there isn't. Location lives in
  the title bar (bottom right), same as every other view.
  Mashup slot dimensions are derived from the screen's own width/height,
  which swap under screen--portrait, so this is not reliably 800x240,
  a portrait-oriented device makes this cell much narrower and taller,
  not wide and short. portrait:layout--col reflows verdict-then-
  forecast to stacked instead of squeezing a row into a cell that is no
  longer wide, same pattern as full.liquid.txt.
  Verdict length varies a lot, same reasoning as Quadrant: fit-to-box
  instead of one fixed font size.

<script type="text/javascript">
(function () {
  // Shrinks every element carrying the framework's data-value-fit
  // attribute until it fits its parent's width. The framework's own Fit
  // Value runtime is meant to do this but did not reliably fire in
  // TRMNL's render pipeline (a forecast word visibly overflowed on a
  // fresh render with the attribute set), so this does the same job
  // with code we know runs. It keys off the framework's attribute rather
  // than a class of our own, so the markup carries no custom classes.
  // If the runtime does fire as well, both only ever shrink, so they
  // cannot fight. Sits outside the aurora.ok branch so the error
  // message is fitted too.
  function shrinkToFit(el, minPx) {
    if (!el) return;
    var container = el.parentElement;
    if (!container) return;
    var guard = 0;
    while (el.scrollWidth > container.clientWidth + 1 && guard < 60) {
      var size = parseFloat(window.getComputedStyle(el).fontSize);
      if (!size || size <= minPx) break;
      el.style.fontSize = (size - 1) + "px";
      guard++;
    }
  }
  var els = document.querySelectorAll("[data-value-fit]");
  for (var i = 0; i < els.length; i++) shrinkToFit(els[i], 14);
})();
</script>
